# Бюджет ремонта

Локальное веб-приложение для разбора смет ремонта: загрузка Excel / CSV / PDF, предоплаты, сверка итогов и аналитика по категориям. Файлы обрабатываются в браузере и на сервер не отправляются.

## Что внутри

- `index.html` — приветственный лендинг
- `app.html` — калькулятор смет
- `examples/sample-estimate.csv` — пример файла для импорта
- `archive/` — исходные однофайловые прототипы

## Как запустить

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 4173
```

Либо:

```bash
npm start
```

Дальше откройте [http://localhost:4173](http://localhost:4173).

## Как пользоваться

1. На главной можно открыть пустой калькулятор или загрузить демо-смету.
2. В калькуляторе укажите вид работ, затем выберите файл `.xlsx`, `.xls`, `.csv` или текстовый PDF.
3. Проверьте строки, при необходимости поправьте их прямо в таблице.
4. Добавьте предоплаты — они идут отдельным журналом, но входят в остаток к оплате.
5. Скачайте результат в Excel.

Черновик сохраняется в `localStorage` браузера, поэтому можно закрыть вкладку и вернуться позже.

## Ограничения

Сканы и фотографии PDF без текстового слоя не разбираются: для них нужен OCR. Если структура PDF нестандартная, извлечённый текст можно поправить вручную и разобрать повторно.
